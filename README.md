# #LiteTexs - Pack Irisbus
Après avoir sorti les remaster de mes textures optimisées sur les Iveco Urbanway/Crealis NP (Nerosy), sur la gamme Urbino IV (Iwo), mais aussi sur l'intégralité des Heuliez GX (Acrotère), je ressors un énième remaster des textures optimisées sur les Irisbus Citelis, Crealis, Crealis Neo et GX127 d'Acrotère.

# Notes:
- Le DLC Irisbus Citelis est requis et vous le retrouverez bien évidemment sur Steam.

# Installation:
Il suffit juste de glisser le dossier OMSI 2 à la racine du dossier où est présent votre OMSI, ex: steamapps/common.
